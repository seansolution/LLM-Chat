# ภาพรวม Work Permit และ Visa

## ใช้กับใครบ้าง

- ชาวต่างชาติที่ต้องการทำงานในประเทศไทย
- บริษัทที่ต้องการจ้างชาวต่างชาติ
- ผู้ที่ต้องการตั้งธุรกิจในประเทศไทย

## สรุปหลักการสำคัญ

Work Permit (ใบอนุญาตทำงาน) คือเอกสารที่ชาวต่างชาติต้องมีเมื่อทำงานในประเทศไทย

### ความสำคัญ

- **ห้ามทำงานโดยไม่มี Work Permit** → ผิดกฎหมาย
- **ต้องมี Work Permit ก่อนทำงาน** → ไม่สามารถทำงานก่อนมีใบอนุญาตได้
- **ต้องต่ออายุทุกปี** → Work Permit มีอายุ 1 ปี

### Visa (วีซ่า)

- **Non-Immigrant B Visa** - สำหรับทำงาน
- **ต้องมี Work Permit ก่อน** → ขอ Visa หลังจากมี Work Permit

## ขั้นตอนหรือข้อกำหนดโดยสรุป

### ขั้นตอนการขอ Work Permit

1. **บริษัทจดทะเบียนในไทย**
   - ต้องจดทะเบียนบริษัทก่อน
   - ต้องมีหนังสือรับรองการจ้างงาน

2. **จัดทำเอกสาร**
   - หนังสือรับรองการจ้างงาน
   - สำเนาพาสปอร์ต
   - ใบรับรองแพทย์
   - วุฒิการศึกษา

3. **ยื่นขอ Work Permit**
   - ที่กรมการจัดหางงาน
   - ใช้เวลา 7-15 วันทำการ

4. **ขอ Visa**
   - หลังจากมี Work Permit
   - ที่สถานทูตหรือสำนักงานตรวจคนเข้าเมือง

## ข้อผิดพลาดที่พบบ่อย

- **ทำงานก่อนมี Work Permit** → ผิดกฎหมาย
- **ไม่ต่ออายุ Work Permit** → ผิดกฎหมาย
- **เอกสารไม่ครบ** → ยื่นขอล่าช้า
- **ไม่ขอ Visa** → ผิดกฎหมาย

## ตัวอย่างสถานการณ์

**สถานการณ์:** บริษัทจำกัดต้องการจ้างชาวต่างชาติเป็นที่ปรึกษา
- ต้องจดทะเบียนบริษัทก่อน
- ต้องมีหนังสือรับรองการจ้างงาน
- ต้องยื่นขอ Work Permit
- ต้องขอ Visa

## เมื่อใดควรปรึกษาผู้เชี่ยวชาญ

- เมื่อไม่แน่ใจว่าต้องขอ Work Permit หรือไม่
- เมื่อต้องการคำปรึกษาเรื่องเอกสาร
- เมื่อต้องการคำปรึกษาเรื่อง Visa
- เมื่อมีปัญหาเรื่องการยื่นขอ

## หมายเหตุ
