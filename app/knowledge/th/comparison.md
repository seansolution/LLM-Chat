# เปรียบเทียบ หจก vs บจก

## ตารางเปรียบเทียบ

| หัวข้อ | ห้างหุ้นส่วนจำกัด (หจก) | บริษัทจำกัด (บจก) |
|--------|------------------------|-------------------|
| **จำนวนหุ้นส่วน/ผู้ถือหุ้น** | 2 คนขึ้นไป | 3 คนขึ้นไป |
| **ความรับผิด** | หุ้นส่วนจำกัด: จำกัดตามหุ้น<br>หุ้นส่วนไม่จำกัด: ไม่จำกัด | จำกัดตามมูลค่าหุ้น |
| **ความน่าเชื่อถือ** | ปานกลาง | สูง |
| **ต้นทุนจดทะเบียน** | 1,000-3,000 บาท | 5,000-10,000 บาท |
| **ความซับซ้อน** | ง่าย | ซับซ้อนกว่า |
| **ระยะเวลา** | 1-2 สัปดาห์ | 1-2 สัปดาห์ |
| **การออกหุ้น** | ไม่สามารถออกหุ้นขายได้ | สามารถออกหุ้นขายได้ |
| **การหาพันธมิตร** | ยาก | ง่าย |
| **ภาระภาษี** | เหมือนกัน (ขึ้นกับรายได้) | เหมือนกัน (ขึ้นกับรายได้) |
| **การจัดการ** | ยืดหยุ่น | มีโครงสร้างชัดเจน |
| **เหมาะกับ** | ธุรกิจขนาดเล็ก<br>เริ่มต้นง่าย | ธุรกิจที่ต้องการขยาย<br>ต้องการความน่าเชื่อถือ |

## ความรับผิด

### หจก
- **หุ้นส่วนจำกัดความรับผิด**: รับผิดจำกัดตามมูลค่าหุ้น
- **หุ้นส่วนไม่จำกัดความรับผิด**: รับผิดไม่จำกัด (ต้องรับผิดหนี้สินทั้งหมด)

### บจก
- **ผู้ถือหุ้นทุกคน**: รับผิดจำกัดตามมูลค่าหุ้นที่ถือ
- **กรรมการ**: รับผิดจำกัด (ยกเว้นกรณีผิดกฎหมาย)

## ภาษี

ทั้งหจกและบจกเสียภาษีเหมือนกัน:
- ภาษีเงินได้นิติบุคคล: 20% (หรืออัตราพิเศษสำหรับ SME)
- VAT: 7% (ถ้ารายได้เกิน 1.8 ล้านบาท/ปี)
- ภาษีหัก ณ ที่จ่าย: ตามอัตราที่กำหนด

## ความน่าเชื่อถือ

### หจก
- ความน่าเชื่อถือปานกลาง
- เหมาะกับธุรกิจขนาดเล็ก
- ลูกค้าบางกลุ่มอาจไม่คุ้นเคย

### บจก
- ความน่าเชื่อถือสูง
- เหมาะกับธุรกิจทุกขนาด
- ลูกค้าและพันธมิตรคุ้นเคยมากกว่า

## ความเหมาะสมกับ SME

### หจก เหมาะกับ:
- ธุรกิจขนาดเล็กที่เริ่มต้น
- ต้องการความยืดหยุ่น
- ต้นทุนต่ำ
- ไม่ต้องการขยายใหญ่

### บจก เหมาะกับ:
- ธุรกิจที่ต้องการขยายกิจการ
- ต้องการความน่าเชื่อถือ
- ต้องการหาพันธมิตรหรือนักลงทุน
- ธุรกิจที่ต้องการโครงสร้างชัดเจน
