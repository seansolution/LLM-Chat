# เงื่อนไขการขอ Work Permit

## ใช้กับใครบ้าง

- ชาวต่างชาติที่ต้องการทำงานในประเทศไทย
- บริษัทที่ต้องการจ้างชาวต่างชาติ

## สรุปหลักการสำคัญ

การขอ Work Permit มีเงื่อนไขหลายประการ ขึ้นกับตำแหน่งงานและประเภทธุรกิจ

### เงื่อนไขหลัก

1. **บริษัทจ้างงาน**
   - ต้องจดทะเบียนบริษัทในไทย
   - ต้องมีหนังสือรับรองการจ้างงาน

2. **ตำแหน่งงาน**
   - ตำแหน่งต้องไม่ถูกจำกัดสำหรับคนไทย
   - ต้องมีวุฒิการศึกษาและประสบการณ์เหมาะสม

3. **สัดส่วนคนไทย**
   - ต้องมีพนักงานไทยตามสัดส่วนที่กำหนด
   - ขึ้นกับประเภทธุรกิจ

4. **เงินเดือน**
   - ต้องไม่ต่ำกว่าที่กฎหมายกำหนด
   - ขึ้นกับสัญชาติ

## ขั้นตอนหรือข้อกำหนดโดยสรุป

### เงื่อนไขบริษัท

- **จดทะเบียนบริษัท** → ต้องจดทะเบียนก่อน
- **หนังสือรับรองการจ้างงาน** → ต้องมีหนังสือรับรอง
- **สัดส่วนคนไทย** → ต้องมีพนักงานไทยตามสัดส่วน

### เงื่อนไขตำแหน่งงาน

- **ไม่ถูกจำกัดสำหรับคนไทย** → ตำแหน่งต้องไม่ถูกจำกัด
- **วุฒิการศึกษา** → ต้องมีวุฒิการศึกษาเหมาะสม
- **ประสบการณ์** → ต้องมีประสบการณ์เหมาะสม

### เงื่อนไขเงินเดือน

- **ยุโรป/อเมริกา/ญี่ปุ่น:** 50,000 บาท/เดือนขึ้นไป
- **เอเชียอื่น ๆ:** 25,000-35,000 บาท/เดือนขึ้นไป
- **ขึ้นกับตำแหน่งงานและประสบการณ์**

## ข้อผิดพลาดที่พบบ่อย

- **ไม่จดทะเบียนบริษัท** → ไม่สามารถขอ Work Permit ได้
- **ตำแหน่งถูกจำกัดสำหรับคนไทย** → ไม่สามารถขอ Work Permit ได้
- **เงินเดือนต่ำเกินไป** → ไม่สามารถขอ Work Permit ได้
- **เอกสารไม่ครบ** → ยื่นขอล่าช้า

## ตัวอย่างสถานการณ์

**สถานการณ์:** บริษัทจำกัดต้องการจ้างชาวต่างชาติเป็นที่ปรึกษา
- ต้องจดทะเบียนบริษัทก่อน
- ต้องมีหนังสือรับรองการจ้างงาน
- ตำแหน่งต้องไม่ถูกจำกัดสำหรับคนไทย
- เงินเดือนต้องไม่ต่ำกว่า 50,000 บาท/เดือน (ถ้าเป็นยุโรป/อเมริกา/ญี่ปุ่น)

## เมื่อใดควรปรึกษาผู้เชี่ยวชาญ

- เมื่อไม่แน่ใจว่าต้องขอ Work Permit หรือไม่
- เมื่อต้องการคำปรึกษาเรื่องเงื่อนไข
- เมื่อต้องการคำปรึกษาเรื่องเอกสาร
- เมื่อมีปัญหาเรื่องการยื่นขอ

## หมายเหตุ

ข้อมูลนี้เป็นคำอธิบายทั่วไป ไม่ใช่คำปรึกษากฎหมายหรือภาษีอย่างเป็นทางการ
กฎหมายอาจมีการเปลี่ยนแปลง โปรดตรวจสอบกับหน่วยงานราชการหรือผู้เชี่ยวชาญอีกครั้ง
