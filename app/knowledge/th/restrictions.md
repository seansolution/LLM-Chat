# ข้อจำกัดและข้อห้ามสำหรับ Work Permit

## ใช้กับใครบ้าง

- ชาวต่างชาติที่ต้องการทำงานในประเทศไทย
- บริษัทที่ต้องการจ้างชาวต่างชาติ

## สรุปหลักการสำคัญ

มีตำแหน่งงานบางตำแหน่งที่ห้ามชาวต่างชาติทำ และมีข้อจำกัดบางประการ

### ตำแหน่งที่ห้าม

1. **งานที่คนไทยทำได้** → ห้ามชาวต่างชาติทำ
2. **งานที่ต้องใช้ใบอนุญาตพิเศษ** → ต้องมีใบอนุญาตพิเศษ
3. **งานที่ถูกจำกัดตามกฎหมาย** → ห้ามทำ

### ข้อจำกัด

- **ห้ามทำงานนอกตำแหน่ง** → ต้องทำงานตามตำแหน่งที่ระบุใน Work Permit
- **ห้ามทำงานนอกสถานที่** → ต้องทำงานตามสถานที่ที่ระบุใน Work Permit
- **ห้ามทำงานเกินเวลา** → ต้องทำงานตามเวลาที่ระบุใน Work Permit

## ขั้นตอนหรือข้อกำหนดโดยสรุป

### ตำแหน่งที่ห้าม

- **งานที่คนไทยทำได้** → ห้ามชาวต่างชาติทำ
- **งานที่ต้องใช้ใบอนุญาตพิเศษ** → ต้องมีใบอนุญาตพิเศษ
- **งานที่ถูกจำกัดตามกฎหมาย** → ห้ามทำ

### ข้อจำกัดการทำงาน

- **ห้ามทำงานนอกตำแหน่ง** → ต้องทำงานตามตำแหน่งที่ระบุ
- **ห้ามทำงานนอกสถานที่** → ต้องทำงานตามสถานที่ที่ระบุ
- **ห้ามทำงานเกินเวลา** → ต้องทำงานตามเวลาที่ระบุ

## ข้อผิดพลาดที่พบบ่อย

- **ทำงานนอกตำแหน่ง** → ผิดกฎหมาย
- **ทำงานนอกสถานที่** → ผิดกฎหมาย
- **ทำงานเกินเวลา** → ผิดกฎหมาย
- **ทำงานตำแหน่งที่ห้าม** → ผิดกฎหมาย

## ตัวอย่างสถานการณ์

**สถานการณ์:** ชาวต่างชาติมี Work Permit เป็นที่ปรึกษา
- **ห้ามทำ:** ทำงานตำแหน่งอื่น (เช่น พนักงานขาย)
- **ห้ามทำ:** ทำงานนอกสถานที่ที่ระบุ
- **ห้ามทำ:** ทำงานเกินเวลาที่ระบุ

## เมื่อใดควรปรึกษาผู้เชี่ยวชาญ

- เมื่อไม่แน่ใจว่าตำแหน่งงานถูกห้ามหรือไม่
- เมื่อต้องการคำปรึกษาเรื่องข้อจำกัด
- เมื่อต้องการคำปรึกษาเรื่องการทำงาน
- เมื่อมีปัญหาเรื่องการทำงาน

## หมายเหตุ

ข้อมูลนี้เป็นคำอธิบายทั่วไป ไม่ใช่คำปรึกษากฎหมายหรือภาษีอย่างเป็นทางการ
กฎหมายอาจมีการเปลี่ยนแปลง โปรดตรวจสอบกับหน่วยงานราชการหรือผู้เชี่ยวชาญอีกครั้ง

**⚠️ สำคัญ: ห้ามทำงานนอกตำแหน่ง/สถานที่/เวลาที่ระบุใน Work Permit → ผิดกฎหมาย**

**ควรตรวจสอบกฎหมายล่าสุดจากเว็บไซต์กรมการจัดหางงานปีละครั้ง**
