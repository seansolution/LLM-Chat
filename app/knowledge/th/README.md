# Knowledge Base - Thai Business Law

## โครงสร้างข้อมูล

ฐานความรู้นี้จัดเก็บข้อมูลกฎหมายธุรกิจไทยสำหรับใช้ในระบบแชทปรึกษาฟรี

## โครงสร้างโฟลเดอร์

```
/knowledge/th/
  ├ company/          # ข้อมูลการจดทะเบียนบริษัท
  ├ tax/              # ข้อมูลภาษี
  ├ accounting/       # ข้อมูลบัญชี
  ├ work-permit/      # ข้อมูล Work Permit
  ├ licenses/         # ข้อมูลใบอนุญาต
  ├ incentives/       # ข้อมูลสิทธิประโยชน์
  └ glossary.md       # คำศัพท์
```

## หลักการจัดเก็บข้อมูล

1. **ไม่คัดลอกข้อความจากเว็บไซต์ราชการโดยตรง**
2. **เขียนสรุปด้วยคำพูดของตัวเอง**
3. **เป็นกลางและเป็นข้อเท็จจริง**
4. **ไม่ให้คำแนะนำทางกฎหมาย**
5. **มี disclaimer ทุกไฟล์**

## การอัปเดต

- แต่ละไฟล์มี `last_updated: YYYY-MM-DD`
- ควรตรวจสอบกฎหมายล่าสุดจากเว็บไซต์หน่วยงานราชการปีละครั้ง

## Metadata

แต่ละไฟล์มี metadata สำหรับใช้ในการจับคู่คำถามในระบบแชท:
- `topic`: หมวดหมู่หลัก
- `subtopic`: หมวดหมู่ย่อย
- `keywords`: คำสำคัญสำหรับการค้นหา
- `difficulty`: ระดับความยาก

## แหล่งข้อมูลอ้างอิง

- กรมสรรพากร
